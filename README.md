# Guess the Number

Historical browser exercise based on Jonas Schmedtmann's JavaScript course. Guess a random integer from 1 through 20. Each incorrect valid guess costs one point; invalid input costs nothing. A win or zero score ends the round. Again starts a new round and keeps the numeric high score for the current page session.

Open `index.html` or run `python3 -m http.server 8000`. Enter submits a guess. The secret number is not logged to the console. This is a learning game, with no persisted accounts or scores.
